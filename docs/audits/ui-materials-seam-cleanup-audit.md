# Аудит очищення квадратних швів і повторів

## Результат

- Оброблено базових матеріалів: **44**.
- Додатково перебудовано великі повторювані плями у **12** проблемних текстурах.
- Зроблено безпечнішими для повторення universal overlays: **6**.
- Середнє зменшення різниці між протилежними краями: **100.0%**.

## Що змінено

- Зрівняно протилежні краї всіх base textures, щоб прибрати квадратні шви при `background-repeat`.
- У хмарних матеріалах замінено великі повторювані плями на детерміновану періодичну низькочастотну структуру зі збереженням мікродеталей.
- Local та edge overlays не перетворювалися на seamless-текстури, бо вони повинні накладатися один раз локально.

## Матеріали, які все ще мають регулярну внутрішню фактуру

- `sealed-plywood` — надто регулярні хвилясті волокна; це не шов, а вміст згенерованої текстури.
- `lead-shielding-metal` — помітні горизонтальні виробничі смуги.
- `institutional-painted-concrete` — регулярна валикова структура.
- `bitumen-waterproofing` — залишилася дрібна повторювана сітка, але квадратні межі послаблені.
- `wired-safety-glass` — регулярна сітка є властивістю матеріалу; не використовувати під щільним дрібним текстом.

Ці п’ять матеріалів можна використовувати обмежено. Для повного усунення їхньої внутрішньої регулярності потрібна перегенерація, а не сильніша програмна обробка.
