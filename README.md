# Bunker / Vault Judgment

## Опис

Онлайн-гра в стилі "Бункер", де гравці отримують унікальні характеристики (вік, професія, здоров'я, хобі, секрети та інше), розкривають їх під час гри, обговорюють та голосують, хто з учасників має вижити.

---

## Функціонал

* Онлайн-кімнати (створення, приєднання, налаштування)
* Синхронізація гри в реальному часі через SignalR
* Генерація персонажів (характеристики, здоров'я, хобі, професії тощо)
* Розкриття характеристик під час гри
* Голосування та виключення гравців
* Host panel (панель ведучого / керування кімнатою)
* Reconnect після оновлення сторінки
* Локалізація (UA / RU / EN)
* Playwright-тести (функціональні, мобільні, навантажувальні)

---

## Як запустити локально

1. Встановити [.NET SDK](https://dotnet.microsoft.com/download) відповідної версії.
2. Відновити залежності:

   ```
   dotnet restore
   ```
3. Зібрати проєкт:

   ```
   dotnet build
   ```
4. Запустити проєкт:

   ```
   dotnet run
   ```
5. Відкрити у браузері локальну адресу, яку покаже ASP.NET Core після запуску (буде виведена в консолі).

---

## Тести

Тести написані на Playwright.

1. Встановити залежності:

   ```
   npm install
   ```
2. Встановити браузери Playwright:

   ```
   npx playwright install
   ```
3. Запустити тести:

   ```
   npm test
   ```

Додаткові команди:

* `npm run test:ui` — запуск тестів у UI-режимі Playwright.
* `npm run test:headed` — запуск тестів у видимому браузері.
* `npm run test:report` — перегляд HTML-звіту після прогону тестів.
